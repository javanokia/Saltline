# Web Audio API 纯声学合成器与 DSP 滤波、卷积混响参考

## 核心设计思想

游戏内不存放任何 MP3、WAV 或 OGG 静态音频文件。所有枪炮击发声、机械换弹碰擦、弹壳跳跃、雨点敲击与动态战术背景音乐，均在客户端基于 Web Audio API 内存实时计算或毫秒级离线预烘焙（OfflineAudioContext）。

---

## 1. 基础物理波形与信号原语 (DSP Primitives)

### 1.1 直接 II 型双二阶滤波器 (Direct Form II Biquad Filter)

在纯数学层面（如生成离线 PCM 缓冲时）直接运用差分方程：
$$y[n] = b_0 x[n] + b_1 x[n-1] + b_2 x[n-2] - a_1 y[n-1] - a_2 y[n-2]$$

- 支持低通（Lowpass）、高通（Highpass）、带通（Bandpass）与陷波（Notch）。
- 用于枪械消音、室内集装箱闷音（850Hz 截止频率）及水下低通滤波。

### 1.2 物理白噪声与粉红噪声 (Pink Noise / $1/f$ 滤波)

- **白噪声**：通过 PRNG 均匀随机生成，模拟子弹初速击发、高压气阀喷射。
- **粉红噪声**：通过 3 级极点极零点滤波衰减白噪声高频（$-3\,\text{dB/oct}$），模拟海风呼啸、暴雨冲刷与大面积火海轰鸣。

### 1.3 模态加法共振 (Modal Resonance Bank)

模拟金属、木材、混凝土受到撞击后的固有谐振频率衰减：
$$s(t) = \sum_{k=1}^{M} A_k \exp(-d_k t) \sin(2\pi f_k t)$$

- **金属敲击**：高 Q 值、非谐波倍频分布（如 $1.0, 2.32, 4.14, 5.86$），衰减较慢。
- **木材敲击**：低 Q 值、快速阻尼，基频在 $120\sim 350\,\text{Hz}$。

## 2. 复合枪声物理生成拓扑 (6-Layer Gunshot Synthesis)

以步枪开火为例，单次射击由 6 层物理声源毫秒级复合叠加：

1. **机械击针碰撞 (Mechanical Click)**：$0\sim 15\,\text{ms}$，极短的高频金属敲击。
2. **超音速子弹激波 (Supersonic Shockwave)**：$5\sim 40\,\text{ms}$，大振幅窄脉冲 N-Wave 激波。
3. **枪膛爆燃 (Chamber Blast)**：$10\sim 120\,\text{ms}$，强失真低频冲量（$60\sim 140\,\text{Hz}$），配以 $tanh$ 软削波饱和。
4. **管路金属共振 (Body Ringing)**：$20\sim 250\,\text{ms}$，模态共振模拟步枪合金机匣嗡鸣。
5. **弹壳抛射抽壳声 (Ejection Clink)**：$80\sim 300\,\text{ms}$，高频金属摩擦与弹簧复进声。
6. **远景海港尾音 (Tail & Slapback Echo)**：$150\sim 1800\,\text{ms}$，多段延时与环境卷积衰减。

## 3. 真实物理脉冲响应 (IR) 卷积混响 (Convolver Reverb)

无需录制真实声学空间脉冲响应，直接通过数学公式程序化生成真实卷积内核：

- **室外集装箱深水泊位 (2.8s)**：
  - 早期反射：利用几何光线追踪法，模拟来自附近集装箱堆垛的数道强离散回声（$30\sim 85\,\text{ms}$）。
  - 后期混响：高斯白噪声乘指数衰减包络 $\exp(-t / \tau)$，高频空气吸收衰减（$HF_{\text{damping}}$）。
- **室内集装箱狭小空间 (1.6s)**：
  - 极密集的高频共振反射，呈现典型的空心钢制长方体回响。
